# 臺灣金融產業情報平台

我設計這個平台，是因為臺灣金融新聞散在不同網站，想追蹤一件事的來龍去脈，常得在好幾個頁面之間切換。我把銀行、保險、證券等產業的消息整理成時間軸，讓讀者能依產業、日期或關鍵字找到想看的新聞。每則新聞先用短摘要交代重點，較複雜的事件可以展開看背景，也能點回原始來源查證。

我也做了一個按產業分類的知識庫，用白話解釋新聞裡常見的名詞和制度。讀者遇到像「借券賣出」這類陌生詞時，可以先看解說，再回來讀新聞。我希望即使沒有金融背景，也能看懂發生了什麼。
